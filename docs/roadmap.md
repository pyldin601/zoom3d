# Roadmap (proposed)

| # | Milestone | Outcome |
|---|-----------|---------|
| 0 | Project setup | Monorepo, TS, lint, test runner, CI, dev server |
| 1 | Single-player walk | Raycaster, map, movement + collision, retro look |
| 2 | Multiplayer presence | Backend WS, rooms + invite link, avatars as colored discs, interpolation |
| 3 | Faces | getUserMedia, face crop, WebRTC, video avatars in the renderer |
| 4 | Spatial audio | Distance gain, panning, reverb bus, wall muffling, tuning UI |
| 5 | Polish | Speaking indicator, mute/cam-off fallback avatars, device picker, perf |
| 6 | Hardening | TURN, reconnects, scaling beyond mesh limits, deployment |

Each milestone gets its own spec/plan before implementation.
