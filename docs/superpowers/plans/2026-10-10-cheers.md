# Cheers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A long press (500 ms) of the held drink's key raises it in a cheers seen by everyone; a short press still sips.

**Architecture:** Cheers mirrors the sip end to end: a one-off `cheers` → `peer_cheers` message relayed by the lobby under the
sip's gap, a pose function and a gesture clock that replaces the sip clock, a per-peer `gesture` in the session, and two more
pose inputs (`cheers`, `wobble`) to the sprite and first-person renderers. A pure press-timing module decides sip vs cheers.

**Tech Stack:** TypeScript, Vitest, pnpm workspace (`packages/shared`, `apps/server`, `apps/web`).

**Spec:** `docs/superpowers/specs/2026-10-09-held-items-design.md` §2.4, §4 (Cheers), §5, §6.3, §6.4, §7 (cheers).

## Global Constraints

- `CHEERS_HOLD_MS = 500`, `CHEERS_MS = 1600`: 300 ms up, 1000 ms held, 300 ms back, eased like the sip (`easeInOut` in `sip.ts`).
- Wobble while held: 2 Hz, amplitude ±0.06 r (others' view), ±1.5% of the view width (own view), scaled by the lift.
- Others' view raised pose: item left edge 0.35 r right of the disc centre, top 1.15 r above it.
- Own view raised pose: left edge at 20% of the width, fully visible, bottom 8% of the view height above the bottom edge.
- One gesture at a time, locally and per remote peer; `DRINK_GAP_MS` (1000) covers sips and cheers together on the server.
- No sound, nothing else drawn. No allocations per frame (AGENTS.md); braces on every `if` body; run `pnpm exec biome check --write .`.

## Review Focus

- Key repeat while held: `keydown` with `e.repeat` must not restart the press (the existing handler already returns on repeat).
- Window blur mid-press (Cmd-Tab): no `keyup` arrives; the press must be cancelled, not fire a cheers on return.
- Picking another drink or `0` mid-press: the press is cancelled (Task 7 test via `drink-press` `cancel`).
- Press while a gesture still plays: nothing starts; the clock refuses it (Task 3).
- A `peer_cheers` from a peer who put the drink down: the server drops it (Task 2), and `peer_held null` clears that peer's gesture (Task 5).
