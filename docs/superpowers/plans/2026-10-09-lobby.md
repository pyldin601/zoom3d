# Lobby Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the join screen with a lobby: a live framed-camera disc with a mic-level ring, camera and mic
split buttons (toggle + device menu), name, picture and Join, where camera off stops the camera.

**Architecture:** A `LocalMediaController` owns local media from the lobby onward and hands it to the room on
Join. The framer's 256² canvas track always exists and is always sent; the camera behind it is swapped or
stopped with `framer.setCamera`, so turning the camera on in the room never renegotiates. The lobby UI renders
from the controller.

**Tech Stack:** TypeScript, Vite, Vitest (+ happy-dom for DOM tests), Playwright (Chrome fake media devices),
Biome.

**Spec:** [docs/superpowers/specs/2026-10-09-lobby-design.md](../specs/2026-10-09-lobby-design.md)

## Global Constraints

- Code style: Biome (`pnpm exec biome check --write .`): 120 columns, single quotes, semicolons, `es5` trailing
  commas, every `if`/`else`/`for`/`while` body braced.
- No allocations in per-frame paths: the mic meter reuses one `Float32Array`.
- User text only ever through `textContent`; the picture only as an `img` `src` attribute.
- `VIDEO_CONSTRAINTS = { width: 640, height: 480, frameRate: 24 }`, `AUDIO_CONSTRAINTS = { echoCancellation: true,
  noiseSuppression: true, autoGainControl: true }` (unchanged, moved).
- Device ids go in as `deviceId: { ideal: id }`, never `exact`.
- Storage key `zoom3d.media`, value `{ cam: boolean, mic: boolean, camId: string | null, micId: string | null }`;
  default `{ cam: true, mic: true, camId: null, micId: null }`.
- Disc 176 px; mic ring 0–6 px wide.
- Error copy (spec §3.6), exact:
  - insecure: `Camera and mic need HTTPS.`
  - cam blocked: `Camera blocked: allow it in the address bar.`
  - mic blocked: `Microphone blocked: allow it in the address bar. You can still listen.`
  - cam missing: `No camera found.` · mic missing: `No microphone found.`
  - cam busy: `Camera is in use by another app.` · mic busy: `Microphone is in use by another app.`
- Accessible names (tests and e2e depend on them): `Turn camera off` / `Turn camera on`, `Choose camera`,
  `Mute microphone` / `Unmute microphone`, `Choose microphone`, `Change picture`, menu items
  `Choose picture…` and `Remove`, name placeholder `Your name`, button `Join`. Room bar keeps `Cam on`/`Cam off`,
  `Mic on`/`Mic off`.
- Tested on Chrome only; Firefox/Safari are not verified (say so in the final report).

## Review Focus

1. Clicking the camera toggle twice fast (on, then off before `getUserMedia` resolves) must end with the camera
   off and its light out: a request that resolves after a newer one is stopped at once (latest wins). Test in Task 4.
2. Switching microphones while muted must keep the new mic muted. Test in Task 4.
3. Clicking Join while a device is still starting (permission prompt open, camera restarting) must not lose
   the mic or leave peers with a stale `cam` flag: Join waits while `state().pending`, and the call republishes
   `media` when the controller changes. Tests in Tasks 5 and 6.
4. Turning the camera on in the room when it has meanwhile gone missing or got blocked: the room bar button
   goes back to `Cam off` and a banner says why. Tests in Task 6.
5. Turning the camera off while the tab is hidden must move senders back to the canvas track, not leave
   them on a stopped camera track. Test in Task 3.

### Task 4: LocalMediaController

**Files:**
- Create: `apps/web/src/media/local-media.ts`

**Interfaces:**
- Consumes: `MediaPrefs` (Task 1), `DeviceProblem`, `Device`, `deviceProblem`, `listDevices` (Task 2), `Framer` (Task 3).
- Produces:
  ```ts
  export const VIDEO_CONSTRAINTS: MediaTrackConstraints;   // moved from capture.ts, same values
  export const AUDIO_CONSTRAINTS: MediaTrackConstraints;
  export interface MediaState {
    cam: boolean; mic: boolean;                  // reality: camera live / mic unmuted and present
    camAvailable: boolean; micAvailable: boolean; // false only for insecure, blocked, missing
    camProblem: DeviceProblem | null; micProblem: DeviceProblem | null;
    pending: boolean;                            // any getUserMedia in flight
  }
  export interface LocalMediaEnv {
    isSecureContext: boolean;
    getUserMedia(c: MediaStreamConstraints): Promise<MediaStream>;
    enumerateDevices(): Promise<MediaDeviceInfo[]>;
    onDeviceChange(cb: () => void): void;
    framer: Framer;
    createStream?(tracks: MediaStreamTrack[]): MediaStream;
  }
  export interface LocalMediaController {
    readonly stream: MediaStream;   // [framer.track] + the mic track once there is one
    readonly framer: Framer;
    readonly ready: Promise<void>;  // initial requests settled
    state(): MediaState;
    prefs(): MediaPrefs;            // the user's intent; changed only by the four setters below
    setCam(on: boolean): Promise<void>;
    setMic(on: boolean): void;
    useCamera(deviceId: string): Promise<void>;
    useMic(deviceId: string): Promise<void>;
    devices(): Promise<{ cams: Device[]; mics: Device[] }>;
    micTrack(): MediaStreamTrack | null;
    subscribe(fn: () => void): () => void;  // state, prefs or device list changed
  }
  export function createLocalMedia(env: LocalMediaEnv, prefs: MediaPrefs): LocalMediaController;
  ```
- Behaviour (spec §3.1–3.3):
  - Start: insecure → both unavailable with problem `'insecure'`, no requests. Otherwise, separately:
    camera only if `prefs.cam`; mic always (its track is kept even when muted, `enabled = prefs.mic`).
    Constraints `{ video: { ...VIDEO_CONSTRAINTS, deviceId: { ideal: camId } } }` (no `deviceId` key when the
    id is `null`), same for audio.
  - Camera on: `getUserMedia` → `framer.setCamera(raw)`. Off: `framer.setCamera(null)` then `raw.stop()`.
  - Each camera request takes a sequence number; a result that is not the latest is stopped on arrival
    (Review Focus 1). Same for the mic.
  - `useCamera` while on: open the new one, `setCamera(new)`, stop the old one. While off: record the id only.
  - `useMic`: open, `stream.removeTrack(old)` / `addTrack(new)`, `new.enabled = state.mic`, stop old.
  - Failure: `camProblem = deviceProblem(err)`; `camAvailable = problem !== 'busy'`; camera stays off.
    A later success clears the problem.
  - A live camera or mic track firing `ended` (unplugged) restarts that device with no `deviceId`.
  - `onDeviceChange` → notify subscribers (lists are re-read by `devices()`).
